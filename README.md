# E-Commerce Sales Analysis – Power BI
## 📊 Project Overview 
This project is an E-Commerce Sales Analysis Dashboard created using Microsoft Power BI. The dashboard provides insights into sales, targets, profit, orders, sub-categories, and geographic sales performance.
## 🛠️ Tools & Technologies 
- Microsoft Power BI
- DAX
- Data Visualization
- - Data Modeling
- Excel
 ## 📌 Dashboard Features
 - Total Sales
 - Sales Target
 - Total Orders
 - - Average Profit
 - Total Profit
- Sales Target Achievement by Category
   - Monthly Sales Trend
   - Profit Margin by Sub-Category
  - Quantity vs Profit Analysis
  - Sales Distribution by Sub-Category
   - Geographic Sales Analysis
  - Sales Performance Matrix
    - Order Count by State
